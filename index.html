🧾 היסטוריית פעולות

כל ההכנסות וההוצאות, מהחדש לישן — עם הסיבה והתאריך.

    📅 פעולות מתוכננות (עוד לא נכנסו ליתרה)

      ➕ הוספת פעולה

      הכנסה או הוצאה, עם סיבה ותאריך. תאריך עתידי ישמור את הפעולה כמתוכננת — היא תיכנס ליתרה כשהתאריך יגיע.

      ✅ משימות שמרוויחים מהן

      כל משימה שהילד משלים מוסיפה את הפרס אוטומטית כהכנסה, עם שם המשימה כסיבה.

      🗓️ דמי כיס אוטומטיים

      סכום קבוע שנכנס אוטומטית כל שבוע או כל חודש. כשהתאריך מגיע, דמי הכיס נכנסים לבד כהכנסה.

      💰 חיסכון קבוע

      סכום קבוע או אחוז קבוע מהיתרה, שנכנס אוטומטית כהכנסה ליתרה כל שבוע או כל חודש — כמו דמי כיס. כל תשלום נרשם בהיסטוריה. זה לא קשור ליעד החיסכון — היעד לא משתנה.

      🎯 יעד חיסכון

      יעד אחד אופציונלי — חוסכים לקראתו ורואים את ההתקדמות. אפשר למחוק אותו בכל רגע.

      💭 כסף דמיוני

      כמה כסף היה לך אם…? מכניסים סכום דמיוני (עד ₪1,000,000) ורואים מה אפשר היה לקנות איתו — ומה החלום הבא. זה לא משנה את היתרה האמיתית.

      ⚙️ הגדרות

      הקישור מכיל את הנתונים כפי שהם עכשיו. אחרי שינויים בקופה צריך ליצור קישור חדש. מי שפותח את הקישור רואה את הנתונים אבל לא יכול לערוך אותם.

      הנתונים נשמרים בדפדפן שלך (localStorage) — קופה נפרדת לכל פרופיל. מחיקת נתוני הדפדפן תמחק את הקופות, לכן כדאי לשמור קישור שיתוף כגיבוי, או לחבר סנכרון Firebase בכרטיס למטה כדי שהקופות יישמרו גם בענן.

      👨‍👩‍👧‍👦 קופות (פרופילים)

      קופה נפרדת לכל ילד — לכל קופה יתרה, היסטוריה, משימות, דמי כיס וחיסכון קבוע משלה. הקופה האחרונה שנבחרה נשארת ברירת המחדל.

      ☁️ סנכרון Firebase

      נרשמים עם מייל וסיסמה והקופות נשמרות בענן — כך הן עוברות בין מכשירים ולא תלויות בדפדפן אחד. הסנכרון חינמי (תוכנית Spark) ולא דורש כרטיס אשראי.

      כדי להפעיל את הסנכרון צריך פרויקט Firebase (חינם, בלי כרטיס אשראי):

      1. יוצרים פרויקט ב־Firebase Console.
      2. מפעילים Authentication → Email/Password.
      3. יוצרים Firestore Database במצב Production ומגדירים את חוקי הגישה (ראו README).
      4. רושמים אפליקציית Web ומדביקים את פרטי התצורה במשתנה FIREBASE_CONFIG בראש הקובץ index.html ומעלים שוב לגיטהאב.

      הנתונים נשמרים במסמך פרטי משלך ב־Firestore — רק החשבון המחובר יכול לקרוא ולכתוב אותו. בלי חיבור, הכל נשמר בדפדפן כרגיל.

      קופת חיסכון לילדים — גרסה עצמאית. הנתונים שלך, בדפדפן שלך.
      אפשר גם לסנכרן בין מכשירים עם מייל וסיסמה (Firebase, חינם) — לא חובה.

      🐷 ברוכים הבאים לקופה!

      קופת חיסכון לילדים — יתרה, היסטוריה, דמי כיס, משימות, יעד חיסכון וכסף דמיוני. אפשר לפתוח קופה לכל ילד, והכל נשמר בדפדפן שלך — ואפשר גם לחבר סנכרון Firebase בהגדרות כדי שהקופות יעברו בין מכשירים.

      אפשר לשנות את השם ואת היתרה אחר כך בהגדרות.
